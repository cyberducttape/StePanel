# Support

StePanel is an early-stage open-source project. Support is community-based
until a stable release is announced.

## Where to ask

- Use [GitHub Issues](https://github.com/cyberducttape/StePanel/issues) for
  reproducible bugs and feature requests.
- Use [GitHub Discussions](https://github.com/cyberducttape/StePanel/discussions)
  for design questions and deployment advice.
- Follow [`SECURITY.md`](SECURITY.md) for suspected vulnerabilities.

Please include the StePanel version, operating system, installation method,
relevant logs with secrets removed, and a minimal reproduction. Never attach
customer backups, passwords, session secrets, or database dumps.

There is no guaranteed response time before the first stable release.
